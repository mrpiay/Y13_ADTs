# Y13 ADTs — Abstract Data Types in Python

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mrpiay/Y13_ADTs/blob/main/tutorial/ADTs_Y13_Tutorial.ipynb)

Array-based implementations of the classic A Level ADTs, plus a full tutorial with exercises.

| File | ADT |
|---|---|
| [stack.py](stack.py) | Stack (LIFO) |
| [queue.py](queue.py) | Circular queue (FIFO) |
| [linked_list.py](linked_list.py) | Linked list with a free list |
| [binary_tree.py](binary_tree.py) | Binary search tree with a free list |
| [main.py](main.py) | Tests and example operations built on the ADTs |

## Tutorial

- **Interactive notebook:** [tutorial/ADTs_Y13_Tutorial.ipynb](tutorial/ADTs_Y13_Tutorial.ipynb). Click the *Open in Colab* badge above, then *File → Save a copy in Drive* so you can write your answers.
- **PDF version:** [tutorial/ADTs_Y13_Tutorial.pdf](tutorial/ADTs_Y13_Tutorial.pdf)

Contents: what an ADT is (and a first look at Big-O) · stack · circular queue · linked list · binary search tree · exam-style tasks combining ADTs with text files · 16 coding exercises with tests and solutions · 4 exam-style tracing questions · summary and exam checklist.

## Running the code locally

```
python main.py
```

> Note: `queue.py` has the same name as Python's built-in `queue` module. Running `main.py` from this folder works, but avoid importing it from other places (e.g. Jupyter), where the built-in module may be loaded instead.

## Rebuilding the tutorial

The notebook and PDF are generated by [tutorial/build_tutorial.py](tutorial/build_tutorial.py) (needs `markdown`, `pygments` and Google Chrome for the PDF):

```
python tutorial/build_tutorial.py . tutorial build
```
